# Ekran görüntüsü kontrol listesi

README'ler aşağıdaki dosya adlarına referans veriyor. ✅ Hepsi gerçek ekran
görüntüsüyle dolduruldu.

Öneriler:
- Raporu **Görünüm → Sayfa görünümü → Gerçek boyut** ile açıp sayfanın tamamını alın.
- Windows'ta `Win+Shift+S` → *Pencere* modu kenar gölgesi bırakmaz.
- PNG kaydedin; sıkıştırmadan kaynaklı metin bulanıklığı olmasın.
- Kişisel/gerçek veri görünmediğinden emin olun — bu raporlar sentetik veriyle çalışır,
  ama yenilemeden önce açtığınız bir dosyanın önbelleğini göstermediğine dikkat edin.
